# 图文与科研配色

1. 对抖音主页、合集和图文，优先打开能确认当前网址的内置浏览器或已获准使用的浏览器会话。核对作者、主页地址和作品区。主页地址带 `vid` 时，用作品区实际出现的链接确定是 `/note/` 还是 `/video/`，并优先查看用户指定的一条。静态请求出现空壳时，从浏览器继续。
2. 做特定主题时，先在作者作品区用平台自带搜索，或进入与主题匹配的作者合集。记录筛选词、窗口或合集范围、实际出现的帖子和页面确认的总量。有明确的「加载更多」或下一页时，按正常页面操作逐批读取，直到结束提示、权限提示或多次加载没有进展。只取作品区或已核对的合集链接，排除侧栏推荐。主页作品总数、合集集数和标题期号是三种不同的计数。
3. 浏览器侧把已经看见的帖子链接汇成 UTF-8 文本；`--douyin-index` 可读取链接、复制的分享文案、可见链接清单，或本地 HTML 里的链接。它去掉跟踪参数、按帖子 ID 去重，并区分图文、视频和未解析短链。索引里的 `pending_review` 仅表示链接已收集。帖子逐条核对后记录「已读色卡」「无可用色卡」「访问受限」或「未查」。在同一范围记录已发现、已判读和未处理数量。只有范围明确、确认没有后续页且所有条目均已判读时才称该范围完整。
4. 对图文，打开原帖并通过其正常图库界面查看每张相关图。页面的头像、封面、评论区图片和推荐图不算原图。可关闭普通提示后验证内容是否公开可见。若仍需登录、验证或访问权限，记录阻塞点，让用户在正常页面操作或直接提供可读截图。外平台同作者内容单列并保留原平台链接。
5. 逐张按原色序保留作者印出的 HEX 或 RGB。两者都有时检查转换；冲突则标记。只有色块时，采样平坦中心的多个像素，用中位数并标为「近似取样」。忽略背景、水印、阴影及示例图配色。
6. 输出标注来源链接、图序或视频时间戳，并区分作者色值和整理者命名、建议。Word 使用原生可编辑色块。只交付 Word 时，临时媒体和清单用单独的临时目录，核验后清理该批临时文件。

~~~powershell
python -B .\scripts\intake.py --douyin-index "D:\data\visible-posts.txt" "D:\data\batch-2.html" --out "$env:TEMP\palette-review"
~~~

若需要长期通过 API 获取作者作品清单，先核对[抖音开放平台的作者列表权限](https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/develop/server/reach-marketing/mount/self_mount/get-user-video-list)、作者授权以及该能力对图文和媒体文件的覆盖范围。
